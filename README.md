# MANAGER - Gestor de Tareas y Productividad

Aplicación SPA desarrollada con React + Vite para la gestión de tareas y productividad de equipos.

---

## Tecnologías utilizadas

- React
- Vite
- React Router DOM
- Tailwind CSS
- SweetAlert2
- JSON Server
- LocalStorage
- Git & GitFlow

---

## Funcionalidades

- Inicio de sesión con LocalStorage
- Protección de rutas
- CRUD de tareas
- Filtros por estado
- Confirmaciones con SweetAlert2
- Diseño responsive
- Persistencia de sesión
- API simulada con JSON Server

---

## Instalación del proyecto

Clonar el repositorio:

```bash
git clone https://github.com/Sebas-1013/MANAGER.git
```

Entrar al proyecto:

```bash
cd MANAGER
```

Instalar dependencias:

```bash
npm install
```

---

## Ejecutar JSON Server

```bash
json-server --watch db.json --port 3001
```

---

## Ejecutar aplicación React

```bash
npm run dev
```

---

## Build de producción

```bash
npm run build
```
